### 👨‍💻 About Me

I am a passionate **Senior DevOps & Cloud Engineer** with over 5+ years of hands-on experience designing, provisioning, securing, and scaling high-availability enterprise cloud platforms.

- 🏢 **Currently:** DevOps & Cloud Engineer at **Perficient Inc**, architecting multi-cloud solutions for global Fortune 500 enterprises.
- ☁️ **Cloud Expertise:** Deep domain expertise across **AWS**, **Microsoft Azure**, and **Google Cloud Platform (GCP)**.
- ⚙️ **Infrastructure as Code (IaC):** Modular, reusable cloud infrastructure orchestration with **Terraform** & **Ansible**.
- 🚢 **Containers & Orchestration:** Production deployment & management of microservices using **Kubernetes (K8s)** and **Docker**.
- 🛡️ **DevSecOps & CI/CD:** Hardening delivery pipelines with automated security audits, vulnerability scanning (AWS Inspector, Trivy, SonarQube), and zero-downtime releases.
- ✍️ **Community & Sharing:** Authoring technical deep-dives on cloud architecture, DevSecOps, and modern platform engineering.
